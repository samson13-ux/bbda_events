# Dossier mémoire — BBDA Events

Tout ce qui sert à la rédaction du mémoire et à la soutenance (hors code du site).

## Contenu

| Sous-dossier / fichier | Utilité |
|---|---|
| `redaction/` | Chapitres et mémoire final (`08-MEMOIRE.md`) |
| `docs/` | Architecture, schéma BDD, règles métier, hébergement, scénario jury |
| `guide/` | Cahier des charges, protocole de stage, guide de développement |
| `screenshots/` | Captures d’écran pour les figures du mémoire |
| `images/` | Photos / visuels de stage |
| `database/` | `schema.sql` et diagramme ER (PDF) |
| `Cours_Rédaction scientifique.pptx` | Cours de rédaction scientifique |

## Site en ligne

Le code qui fait tourner le site reste à la **racine** du dépôt (`app.py`, `backend/`, `frontend/`, etc.).
